# OpenSpec 本地只读可视化界面设计

## 目标

为已安装的 OpenSpec CLI 提供 `openspec ui [path]`。该命令在用户当前工程中启动一个本机浏览器界面，用于只读浏览和全文检索：

- `openspec/**` 的全部可读文本内容；
- `docs/superpowers/plans/**` 的计划文档。

界面帮助用户在使用工程期间快速定位业务说明、活动与归档 Change、Spec 和 Superpowers 计划。首版不修改任何工程文件或文档。

## 范围与约束

- 目标目录为命令传入的路径，省略时为当前目录。
- 服务仅绑定 `127.0.0.1`，不提供远程访问、认证、多用户或同步能力。
- 浏览器端不得直接读取文件系统；所有内容经由 CLI 启动的本地 API 返回。
- 扫描范围严格限定为工程根目录下的 `openspec/` 与 `docs/superpowers/plans/`。不将其他 `docs/` 内容纳入索引。
- 首版通过“重新扫描”按钮或刷新页面更新内容，不监听文件变化。

## 用户流程

1. 用户在工程目录运行 `openspec ui`，或传入目标工程路径。
2. CLI 验证路径，建立只读内容索引，在可用端口启动本地 HTTP 服务，并自动打开浏览器。
3. 用户通过目录树展开分类、在文件列表中选择文档，或用全局搜索定位内容。
4. 用户在阅读区查看 Markdown 渲染结果；刷新页面或点击重新扫描后获得最新索引。
5. 用户停止 CLI 进程时，本地服务一并关闭。

## 架构

### 命令与服务生命周期

UI 命令负责解析路径、验证工程、选择可用端口、启动和关闭服务，并调用现有的跨平台打开器打开默认浏览器。服务失败、端口不可用或浏览器无法打开时，命令行输出可操作的诊断及可手动访问的本地 URL。

### 内容索引器

索引器递归扫描两个白名单根目录，忽略二进制文件、符号链接逃逸和超过设定上限的文件。每条索引记录包含稳定 ID、工程相对路径、来源类别、标题、正文、修改时间与用于搜索的标准化文本。Markdown 是主要阅读内容；YAML 保留其原始结构并可提取 Change 状态、编号和时间等元数据标签。

OpenSpec 在导航层按以下逻辑分组：业务说明、活动 Change、当前 Spec、归档 Change、归档 Spec 和其余可读文件。Superpowers 内容显示为独立的 Plans 分组。

### 本地 API

本地 API 提供目录树、文件详情、搜索和重新扫描端点。读取文件时只接受索引 ID；不接受任意文件路径，因此请求不能突破扫描根目录。所有响应显式标明错误、空状态和内容不可用原因。

### 浏览器界面

前端是随 CLI 发布的静态资源，通过本地 API 加载数据。它不保存编辑状态，也不执行文件系统写入操作。

## 界面与交互

采用三栏布局：

- 左栏：`OpenSpec` 与 `Superpowers Plans` 两个顶级目录，OpenSpec 按内容类别分组；默认展示 Markdown 内容，并将 YAML 放在可折叠的“配置与元数据”分组。
- 中栏：当前分类或搜索结果，显示标题、相对路径、类别、更新时间和命中摘要；YAML 条目额外显示从其内容提取的状态、编号或时间标签。
- 右栏：Markdown 阅读器渲染标题、表格、代码块、引用和任务清单；YAML 以保留缩进的原始文本显示，不转换为 Markdown。两者均显示完整相对路径，并提供复制路径及在平台支持时于文件管理器中打开。

顶部全局搜索覆盖标题、路径和正文，支持类别筛选与关键词高亮。结果优先级为标题命中、路径命中、正文命中，再以修改时间排序。当前文件、查询词和筛选条件编码进 URL，以支持刷新和共享本地链接。

找不到可读内容、搜索无结果、Markdown 渲染失败等情况均应给出明确提示。解析失败的文本仍可按原始文本显示，且不影响其他文档浏览。

## 模块边界

1. UI 命令与生命周期模块：启动、端口选择、浏览器打开与进程清理。
2. 内容索引模块：受限扫描、分类、元数据提取和全文检索。
3. 本地 API 模块：为前端提供只读数据，执行索引 ID 和路径安全校验。
4. 前端资源模块：三栏导航、搜索、阅读、重新扫描和错误状态。
5. 构建集成：将前端静态资源复制至现有 `dist` 产物，并纳入 npm 发布文件。

## 错误处理与安全

- 目标路径不存在或缺少两个来源目录时，继续启动可用界面并明确指出缺失的来源。
- 两个来源都不存在或没有可读文件时，展示空状态，不静默退出。
- 端口占用时自动选择其他本地端口；无法启动时返回非零退出码和诊断。
- API 仅提供索引中的内容，拒绝未知 ID 与路径穿越请求。
- 忽略二进制、超大或目录外的文件，并记录可面向用户说明的跳过原因。

## 测试与验收

自动化测试覆盖：

- 命令参数、默认路径与浏览器打开调用；
- 仅索引两个允许根目录，且包含 OpenSpec 归档内容；
- 空目录、缺失目录、无可读 Markdown、不可读文件及中文/英文内容；
- 目录树和文件内容 API；
- 标题、路径和正文的全文检索及类别筛选；
- 未知 ID 与路径穿越防护；
- 重新扫描和端口占用回退。

验收标准是：用户运行单一 `openspec ui` 命令即可进入本地浏览器；能浏览所有指定来源内容、全文检索并阅读 Markdown；界面与服务全程不修改工程文件。

## 非目标

首版不包含编辑、创建或归档内容、远程访问、账号认证、实时文件监听、文件上传、在线同步、搜索历史和除 `docs/superpowers/plans/` 之外的普通文档浏览。
